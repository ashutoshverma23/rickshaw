# Rickshaw

Rickshaw is a full-stack MERN (MongoDB, Express, React, Node.js) application that helps digitalize or automate Rickshaw finding by Passengers and vice versa. The platform provides features like user authentication, geolocation-based functionalities, and an interactive map for navigation.


https://github.com/user-attachments/assets/b9293216-19dd-4c94-bdbd-7ca8231242f1


## Features

- User Authentication with JWT
- Interactive map with `react-leaflet` and OpenStreetMap
- Role-based access for drivers and passengers
- Live location tracking
- Secure backend API for user data management

## Installation Guide

Follow these steps to install and run Rickshaw on your local machine:

### Prerequisites

1. Node.js and npm installed on your machine.
2. MongoDB set up locally or a connection string to MongoDB Atlas.
3. Git installed for version control.

### Steps to Install

1. **Clone the Repository**
   ```bash
   git clone https://github.com/ashutoshverma23/rickshaw.git
   ```
2. **Install the required modules and run**  **Frontend**
   ```bash
   cd rickshaw
   cd frontend
   npm install
   npm run dev   
   ```
   **Backend**
   ```bash
   cd backend
   npm install
   npm start
   ```
